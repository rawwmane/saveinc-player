# SAVEINC SP-01 — прототип интерфейса

Собранный браузерный прототип офлайн-плеера SAVEINC в форм-факторе iPod Classic: колесо со щелчками и упорами, крейты из данных Discogs, «Дигать», Скретч-лаб, 1-битный экран.

Открыть: https://rawwmane.github.io/saveinc-player/

Здесь только собранный сайт. Видео — через официальный встроенный плеер YouTube. Данные и обложки — Discogs. `demo/scratch.bin` — зашифрованный демо-трек для Скретч-лаба; без ключа из личной ссылки он не воспроизводится.
